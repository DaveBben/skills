# Plan step: crossings

A crossing is a place the walking skeleton's outcome passes from one running piece into another: a database, a third-party API, a host, a device, a queue, another repository. List each one, ask which someone has already made work in this stack, and run a spike by "Run a spike" in `SKILL.md` for each untried one before going on, framed as a question that can fail ("the app can read Health data while the phone is locked").

Then read `plan-numbers.md` in this folder.
